# Инструкции по настройке целей в Яндекс.Метрике

## Войти в Яндекс.Метрику
1. Перейти на https://metrika.yandex.ru/
2. Выбрать счётчик 105466132
3. Перейти в раздел "Цели"

## Создать следующие цели:

### Цель 1: Клик по кнопке "Записаться"
- **Название:** CTA Click
- **Тип:** JavaScript событие
- **Идентификатор:** cta_click
- **Описание:** Пользователь нажал на любую кнопку "Записаться"

### Цель 2: Отправка формы
- **Название:** Form Submit
- **Тип:** JavaScript событие  
- **Идентификатор:** form_submit
- **Описание:** Успешная отправка формы обратной связи

### Цель 3: Клик по Telegram
- **Название:** Telegram Click
- **Тип:** JavaScript событие
- **Идентификатор:** telegram_click
- **Описание:** Переход в Telegram для связи

### Цель 4: Просмотр раздела "Стоимость"
- **Название:** Pricing View
- **Тип:** URL
- **Условие:** содержит
- **URL:** #pricing

### Цель 5: Просмотр страницы "Образование"
- **Название:** Education Page
- **Тип:** URL
- **Условие:** содержит
- **URL:** education.html

## После настройки целей

Вы сможете отслеживать в отчётах:
- Конверсию сайта (сколько % посетителей оставляют заявку)
- Какие источники трафика дают больше заявок
- На каком этапе воронки теряются пользователи

## Рекомендуемые отчёты для просмотра:
1. **Отчёт по целям** → Конверсия
2. **Источники трафика** → Откуда приходят клиенты
3. **Карта кликов** → Где кликают пользователи
4. **Вебвизор** → Записи сессий (как люди пользуются сайтом)

## Целевые значения конверсии:
- **CTA Click:** 15-25% (хороший показатель)
- **Form Submit:** 3-7% (отличный показатель)
- **Telegram Click:** 5-10%

Если конверсия ниже — нужно работать над UX и контентом.
