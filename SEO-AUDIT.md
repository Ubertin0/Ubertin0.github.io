## ⚠️ Что нужно улучшить

### 1. Отсутствует og:image (КРИТИЧНО)

**Проблема:** При публикации ссылки в соцсетях/мессенджерах не показывается превью.

**Решение:**
```html
<meta property="og:image" content="https://balandinatherapy.ru/og-image.jpg">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="Наталья Баландина - Психолог-консультант">
```

Нужно создать изображение 1200x630px:
- Ваше фото
- Текст: "Русскоязычный психолог онлайн"
- Фон в стиле сайта (бежевый)

### 2. Twitter Card

```html
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="Русскоязычный психолог online | Наталья Баландина">
<meta name="twitter:description" content="Глубокое психологическое консультирование для русскоязычных клиентов по всему миру">
<meta name="twitter:image" content="https://balandinatherapy.ru/og-image.jpg">
```

### 3. Alt-теги для изображений

**Текущее:**
```html
<img src="photo.jpg" alt="Наталья Баландина — Психолог">
```

**Лучше:**
```html
<img src="photo.jpg" 
     alt="Наталья Баландина, психолог-консультант, ЛОРП-практик. Онлайн консультации для русскоязычных клиентов по всему миру"
     loading="lazy">
```

### 4. Заголовки H1-H6

**Проверка структуры:**

**Оценка: 9/10** - структура правильная

## 🤖 AI SEO (для ChatGPT, Perplexity, SearchGPT)

### Что уже работает:

1. **Структурированные данные** - ✅
2. **Четкая семантика** - ✅
3. **Canonical URLs** - ✅

### Что добавить:

#### 1. FAQ Schema (для голосовых ассистентов)

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "Как понять, что мне нужен психолог?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Если вы чувствуете, что не справляетесь самостоятельно..."
      }
    }
  ]
}
</script>
```

**Эффект:** Появление в Featured Snippets Google + ответы ChatGPT

#### 2. BreadcrumbList Schema

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    {
      "@type": "ListItem",
      "position": 1,
      "name": "Главная",
      "item": "https://balandinatherapy.ru/"
    },
    {
      "@type": "ListItem",
      "position": 2,
      "name": "Блог",
      "item": "https://balandinatherapy.ru/blog.html"
    }
  ]
}
</script>
```

#### 3. Article Schema для постов блога

Уже есть ✅, но можно улучшить:
- Добавить `author.sameAs` (ссылки на соцсети)
- Добавить `publisher` (организация)
- Добавить `mainEntityOfPage`

#### 4. Обогащённые сниппеты (Rich Snippets)

**Добавить в Schema для услуг:**

```json
{
  "@type": "Service",
  "name": "Онлайн консультация психолога",
  "description": "Глубокое психологическое консультирование",
  "provider": {
    "@type": "Person",
    "name": "Наталья Баландина"
  },
  "offers": {
    "@type": "Offer",
    "price": "4000",
    "priceCurrency": "RUB",
    "priceValidUntil": "2026-10-31",
    "availability": "https://schema.org/InStock",
    "description": "Осеннее предложение - скидка 1000₽"
  }
}
```

**Эффект:** Цена показывается прямо в поиске Google!

## 🎯 Ключевые метрики для отслеживания

### Google Search Console:
- Impressions (показы) - сколько раз сайт показывается в поиске
- Clicks (клики) - сколько переходов
- CTR (Click-Through Rate) - процент кликов
- Average Position - средняя позиция в выдаче

**Цель:** Position < 10 (первая страница) для запросов:
- "психолог онлайн русскоязычный"
- "психолог для экспатов"
- "психолог за рубежом"

### Яндекс.Вебмастер:
- Индексация страниц
- Ошибки обхода
- Качество сайта (ИКС - Индекс Качества Сайта)
