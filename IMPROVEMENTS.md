# План улучшений balandinatherapy.ru

## 🎯 Критичные улучшения (для роста конверсии)

### 1. Оптимизация изображений (производительность)
**Проблема:** photo.jpeg = 2MB, photo.jpg = 473KB
**Решение:** 
- Конвертировать в WebP (экономия ~70%)
- Использовать responsive images
- Lazy loading

**Влияние:** Ускорение загрузки → снижение показателя отказов → больше заявок

### 2. Lead-магнит для сбора контактов
**Проблема:** 1-2 заявки в месяц - слишком мало для масштабирования
**Решение:**
- PDF-чеклист "5 признаков, что вам нужна психологическая помощь"
- Или "Как подготовиться к первой сессии с психологом"
- В обмен на email → база для email-рассылки

**Влияние:** Увеличение касаний с аудиторией, повторные заходы

### 3. Pixel и аналитика для отслеживания
**Проблема:** Не отслеживаете метрики
**Решение:**
- Настроить Яндекс.Метрику цели (клик на "Записаться", отправка формы)
- Google Analytics 4 события
- Pixel ВКонтакте для ретаргетинга

**Влияние:** Понимание что работает, куда вкладывать деньги

### 4. Telegram Widget для мгновенной связи
**Проблема:** Форма обратной связи - барьер
**Решение:** Встроенный Telegram виджет (открывается чат прямо на сайте)

**Влияние:** Снижение барьера входа → больше диалогов

### 5. Онлайн-календарь записи
**Проблема:** Нужен обмен сообщениями для выбора времени
**Решение:** 
- Calendly (бесплатный тариф)
- Или Yclients
- Клиент сам видит свободные слоты

**Влияние:** Автоматизация, снижение трения в воронке

### 6. Посадочная страница для Telegram-трафика
**Проблема:** Трафик с канала идёт на главную
**Решение:** 
- Отдельный landing `/telegram.html` с упоминанием канала
- Персонализированное предложение для подписчиков
- UTM-метки для отслеживания

**Влияние:** Выше конверсия специфичного трафика

## 🚀 Масштабирование

### 7. Email-рассылка (для прогрева аудитории)
- Раз в 2 недели: статья + анонс новых форматов
- Сервис: SendPulse (бесплатно до 500 подписчиков)

### 8. Групповые программы (для масштабирования)
- Отдельная страница `/group.html`
- Описание формата, стоимости
- Вебинары или мини-курсы

### 9. SEO-оптимизация для органического трафика
- Контент под запросы: "психолог онлайн", "консультация психолога для экспатов"
- Локальное SEO (если есть целевые города)
- Внешние ссылки (гостевые посты на профильных ресурсах)
