## 3. Оптимизация alt-тегов в старых статьях

### Текущее состояние
- В статьях используются фоновые изображения через CSS свойство `background-image` в div элементах
- Теги `<img>` в содержимом статей не используются
- Следовательно, традиционные alt-теги не применимы

### Рекомендации
Поскольку это дизайнерское решение использовать фоновые изображения, для улучшения доступности можно рассмотреть следующие варианты:

1. **Добавить aria-label к контейнерам с фоновыми изображениями** в карточках статей в разделе "Возможно, вас заинтересует"
2. **Использовать теги <img> вместо фоновых изображений** для фактического контента статей (если такие изображения добавятся в будущем)
3. **Добавить описывающие заголовки и контекст** вокруг изображений для улучшения семантического понимания

### Пример улучшения доступности для карточек статей:
Вместо:
```html
<div class="article-card__image" style="background-image: url('image-url.jpg')"></div>
```

Можно использовать:
```html
<div class="article-card__image" 
     style="background-image: url('image-url.jpg')" 
     aria-label="Описание изображения для статьи [заголовок статьи]">
</div>
```
